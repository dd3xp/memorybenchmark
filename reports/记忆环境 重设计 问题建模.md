# 从环境信息结构重建跨 session 记忆实验

研究日期：2026-10-25。本文提出问题建模与设计方法；新玩法尚未选定，游戏与部署配置未改动。

**本项目最接近“在共享、初始未知的世界中，跨多个任务积累信息并改善行动”的问题。** Agent 要解决的是带未知规律的序贯决策；我们要解决的是怎样构造环境，并用受控实验检验其自主记忆的作用。图提供可分析的行为记录，但有效信息首先必须来自环境机制。因此，本轮应先确定行动、反馈、未知规律与重置边界，再用两个匹配世界验证历史的行动价值，最后选择地图和委托。现有引擎、会话隔离与轨迹记录可以继续使用，八项委托的衔接暂缓重做。

## 重设计从基本交互与信息边界开始

已确认范围见 [环境基本规则与信息结构](../docs/ENVIRONMENT_REDESIGN.md)。需要重新决定的是：哪些操作改变什么，什么信息初始未知、怎样由实际行为揭示、在什么范围内持续有效，以及任务边界重置哪些状态。“到达自动测绘、工具自动生效、危险只扣体力”均是待审查规则；它们不必全部废弃，也不能预先默认成立。地点数量、危险数量和工具数量同样不能替代机制设计。

保持的研究约束是：独立 session 之间清除临时上下文；经验由 Agent 自己形成和保存；公共地图只提供地理成果，各对照条件一致；探索自由，每项任务均可学习和利用经验。先不固定能力维度、评分公式或唯一正确轨迹。**本轮首先要填写的是环境契约，而不是八项委托表。**

## 多回合未知世界决策解释记忆为什么有用

把世界真相与 Agent 的知识分开，模型就清楚了。记稳定但初始未知的世界规律为 `θ`，当前位置、资源、库存和任务进度等短期状态为 `x`，当前目标为 `q`，公共地理信息为 `B`，Agent 自己保存的记忆为 `m`。行动依世界规律产生后果与反馈，可简写为 `x_next ~ Tθ(x, action)`。多个任务共享 `θ`，而 `x` 按明确规则初始化；新 session 清除临时上下文，保留规定的 `B` 与 `m`。`θ` 是环境真相，`m` 是 Agent 实际留下的信息，二者不能混用。

即使位置、体力和当前条件完全可见，Agent 仍可能不知道某操作在这里的后果：这可看成**未知 MDP**。若当前物理状态也只能局部观察，则可用**未知 POMDP**。把未知参数及其不确定性纳入决策，又得到 Bayes-adaptive 视角；把固定参数加入隐藏状态，也能写成增广 POMDP。这些是不同建模重点，并非互斥归类。([Ross 等关于未知模型与状态不确定性的建模](https://www.jmlr.org/papers/v12/ross11a.html))

“任务重置、世界规律延续、信息跨任务保留”的组织方式，也接近多 episode 适应。RL² 在同一 MDP 的多个 episode 间保留循环状态，但还包含跨 MDP 的外层训练；我们只借用这种组织结构，**不要求训练 RL、更新模型参数或采用贝叶斯记忆**。([RL² §2.2](https://arxiv.org/pdf/1611.02779)) 当前可见条件与稳定规律也要分开：历史可帮助解释雨天的后果，不意味着应知道未来何时下雨。

图论侧，通行部分接近“地图已知，局部通行事实或实际代价逐步揭示”的在线决策。Canadian Traveller Problem 的经典设定是已知道路图、到达邻接节点才揭示部分道路能否通行；同一论文也研究局部揭示的未知边长。([Shortest paths without a map §1、§4](https://sites.cs.ucsb.edu/~suri/cs235/Rlist/noMapNavigation.pdf)) 本项目另有跨 session 自主保存、不同目标及行动状态对结果的影响，不能把完整研究等同于 CTP。它提供的是通行子问题的参照，不是现成的记忆评测方法。

## 用匹配世界检查历史是否真正改变行动价值

以下是根据上述建模提出的设计方法。先只构造**一个二值持久未知机制**，形成两个世界：公开地图、当前目标、起点和直接可见条件相同，只有某项稳定规律不同。然后检查三个关系：当前输入不能直接区分两世界；先前合法交互能够产生区分证据；拥有这些证据会改变后续合理策略的后果或代价。无需规定唯一正确动作，但要检查完整执行，不能只因两个世界的最优首步不同就宣告成立。

还必须检查绕过历史的免费方案：现场说明是否重新完整播报答案，一个固定保守策略或“全部准备”是否在两世界同样好，重新调查是否已经顺路且没有额外代价。若要声称排除了全部免费通用策略，需要在明确的有限状态与动作预算内穷举相关策略；少量手工轨迹只能排除已检查的例子。**无记忆者仍可通过调查成功**，不必人为设计成必败；历史的价值可以表现为少做无效访问、提前准备或减少重复尝试。未知配置应在多个世界间平衡，避免地名、任务编号、常识或固定动作偏好替代实际历史。

机制候选可以来自三种简单结构：局部操作有不同的持久效果；公开条件与有效操作存在简单对应；不同地点具有需亲自发现的服务能力。它们分别偏向行动后果、条件对应和局部事实记忆，**尚未选择其中任何一种**。只改变按钮的正确答案，可能不足以为地点通勤图增加信息；为了图形变化强迫绕路，同样不能成立。

对小型机制，评测器可以枚举所有参数配置，并维护“与实际交付反馈相容的世界集合” `K(H)`。完整证据可能区分两世界，部分证据可能仍允许多种解释。这个集合是分析工具，既不是 Agent 的真实信念，也不表示它已经理解或保存了证据。前一任务失败仍可能提供信息，成功也可能没有接触关键来源。

Alchemy 的启发在于可枚举的隐藏参数、清晰的重置边界，以及区分基于历史的 ideal observer 和直接知道真相的 oracle；其复杂 chemistry 推断与规划不必移植。([Alchemy §3–4](https://arxiv.org/html/2102.02926v3#S3)) MemoryArena 则提供跨 session 信息依赖的构造原则，不要求我们复制所有强依赖链。([MemoryArena §3.1–3.2](https://arxiv.org/html/2602.16313v2#S3.SS1))

## 用参考搜索和匹配干预降低推理混淆

理论上，可以根据历史维护可能世界，再规划兼顾任务收益与获证收益的策略；Bayes-adaptive 搜索提供这类求解思路。([BAMCP §2–3](https://arxiv.org/pdf/1205.3109)) 本项目先用有限机制的小规模穷举即可。已知规律时，在“地点＋影响后果的状态＋进度”的辅助状态图上搜索，检查可解性、资源范围和意外捷径；按实际证据限制可能世界，再检查仍需调查什么。**这些参考策略服务于设计验证，不是要求 Agent 复刻的 GT。**

尤其要核对“相关信息已经可用以后，行动是否直接”。应避免靠微小路线成本差、多工具组合和长程排序制造主要区别。完整隐藏真值只用于可解性与规划校验；它可能包含从未暴露的信息，不能当作 Agent 的记忆上限。

正式实验中，较合适的局部干预是从**同一段实际历史**建立检查点，保持当前任务、环境和公共地图一致，分出保留／清除规定记忆通道的分支。比较不同 Agent 时，各自形成历史，再在各自历史上配对，不能默认它们获得了相同证据。完整任务流另行保留，以观察自主探索造成的长期差异。

辅助诊断可以将该次历史真正返回过的相关**原始反馈及出处**恢复到当前上下文，检查信息在眼前时是否仍难以行动。评测器不能把模糊反馈提炼成唯一正确结论后注入，也不能补入未见真值。该条件改变了检索和信息呈现，只用于诊断；它与正式条件的差值不能严格拆成“纯记忆损失”。记忆、理解、规划和执行仍相互作用。

## 先交付一个可验证机制，再扩展地图任务

地点仍为节点，每次实际通勤为独立有向边，保留顺序、重复、进入状态与真实代价；原地操作和反馈作为地点关联事件。检查提前行动、现场重查、遇到后返回、重复尝试等合法策略是否留下可追溯的区别。环和折返本身没有固定好坏含义。若机制最终只留下按钮正确率，通勤图就没有提供额外分析信息，应重新判断机制或表示的适配性。

下一步的具体交付物是：

1. **一页环境契约**：动作、状态后果、可见反馈、持久未知量及 session 重置规则，明确 Agent 与评测器各自的信息边界。
2. **一个二值机制与两个匹配世界**：保持同一公开地图和目标，用小规模枚举检查获证可达性、历史价值、免费捷径和已知证据下的决策难度。
3. **几条合法真实交互及其图导出**：覆盖充分证据、部分证据、未获证据和重新调查，核对行为差别被保留下来。通过后再选择空间结构、组织八项委托，随后接入真实 Agent。
