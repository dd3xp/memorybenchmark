# 地点通勤图与未知图探索：问题归属及可用方法

研究日期：2026-10-25。本文只讨论图论／在线算法这一侧。环境整体的部分可观察决策建模另行讨论；以下对应关系不要求游戏变成纯粹的最短路竞赛，也不冻结新玩法。

## 最接近哪类问题，与经典模型有何区别？

### Takeaway

在“公共地理拓扑可以知道，但局部通行规则和实际代价需要经历才知道”这一设定下，最接近的是**带局部信息揭示的在线通行决策**，尤其是 Canadian Traveller Problem（CTP）和未知边长路径问题。跨任务保留经验、目标变化、行动状态影响结果，则是本项目在这一基础上的额外要求；不能直接宣称等同于某一个经典问题。

### Cited Findings

- **已知地图、未知通行状态：CTP。** Papadimitriou 与 Yannakakis 的 *Shortest paths without a map*（TCS，1991）在 §1、印刷页 129 的 Fig. 3 说明：道路图已知，部分道路是否可通行要到达邻接节点才揭示。其目标是设计相对于完整实例最短可行路径具有保证的在线策略；§4 的 Corollary 4.2 证明该特定竞争比决策问题为 PSPACE-complete。该结论不是说普通 Dijkstra 难，也不是对所有导航任务的统一复杂度判断。[原论文，§1、§4](https://sites.cs.ucsb.edu/~suri/cs235/Rlist/noMapNavigation.pdf)
- **已知拓扑、未知局部边长：同一论文的 double-valued graph。** §4、印刷页 142 给每条有向边两种候选长度，到达起点节点后才知道实际长度；Theorem 4.1 研究在线策略能否保证给定最坏情况比值。它直接说明“拓扑公开”并不等于“完整决策信息公开”。[原论文，§4](https://sites.cs.ucsb.edu/~suri/cs235/Rlist/noMapNavigation.pdf)
- **未知拓扑、需要全图覆盖：online graph exploration。** Fritsch 的 *Online Graph Exploration on Trees, Unicyclic Graphs and Cactus Graphs*（2021 论文版本）§1 定义：首次到达节点时揭示相邻节点标识和关联边权，目标是访问所有节点并回到起点；竞争分析的全知对照为最短覆盖游程。本文关于 Nearest Neighbor 与 Blocking 的界限针对其明确定义的图类别及探索目标。[原论文，§1、§1.1](https://arxiv.org/html/2004.06690v2)
- **重复选择路径并累积反馈：部分监测在线最短路。** György 等的 *The On-Line Shortest Path Problem Under Partial Monitoring*（JMLR，2007）§2–3 使用已知有向无环图、固定源终点；每轮选择整条路径，之后只观察所选边损失，或仅整条路径总损失。§4 的算法估计边收益并更新权重，以控制相对最佳固定路径的遗憾。[原论文，§2–4](https://jmlr.org/papers/volume8/gyoergy07a/gyoergy07a.pdf)
- **事实已知、资源有限：resource-constrained shortest path。** Ahmadi 等的 *A Fast Exact Algorithm for the Resource Constrained Shortest Path Problem*（AAAI，2021）Introduction 定义最小化路径成本且资源消耗不超预算；其 RC-EBBA* 在已给定的成本、资源与图上进行精确搜索。正文 “Our Enhanced Biased Bidirectional A*” 及 Algorithm 2 用节点、已用资源、累计成本和启发式界记录部分路径。[原论文，Introduction、Algorithm 2](https://ojs.aaai.org/index.php/AAAI/article/download/17450/17257)

### Inferences

以下是把上述定义与本项目的[重设计范围](../../docs/ENVIRONMENT_REDESIGN.md)比较得到的推断，不是原论文对我们的结论。

| 经典问题 | 与本项目相近的部分 | 不能直接覆盖的部分 |
| --- | --- | --- |
| CTP／未知边长在线路径 | 地图已知仍有局部未知事实；行动同时带来通行结果与信息 | 经典设定没有规定 Agent 自主写入、检索跨 session 记忆；通常一项起终点任务，不包含工具／条件对通行结果的主动改变 |
| 在线全图探索 | 到达地点揭示局部信息，探索与回访均成为真实游走 | 本项目不要求每项任务全图覆盖；公共地理图会逐步公开，路线记忆也不是唯一研究重点 |
| 部分监测在线最短路 | 只从实际执行得到反馈，历史可指导下一轮 | 原论文按整条路径进行一轮决策、固定源终点，不含途中取物和改变状态；其参数／权重直接跨轮保留，不检验 session 清空后自主经验保存是否有效 |
| 资源约束最短路 | 已知局部事实后，核对预算内是否存在合法执行方案 | 不解决哪些事实能被经历揭示、为何需要历史，也不测记忆是否被保留或使用 |

因此更准确的工作描述是：**在有持续未知局部规则的地理图上，进行多个目标任务；行动产生反馈，Agent 自主保存经验，再以之后的行动体现其价值。** 图论模型可帮助定义和校验其中的通行部分；研究问题还包含跨 session 信息保存与行动归因。

### Gaps

- 这四篇不能支持“我们已提出新图论问题”或“此前没有相同 benchmark”的主张；它们用于澄清模型和借用解法，不是完整 novelty 核查。
- 尚未确定新玩法中未知的是代价、通行前提、局部操作规律还是其他事实，现阶段不能把 CTP 当成已经选定的唯一正式模型。

## 已有解法可以怎样帮助重设计，又不能替我们解决什么？

### Takeaway

把“给定世界事实后的执行可行性”与“经历能否提供有价值的信息”分开校验。前者可以做图搜索，后者需要显式记录可能世界与实际暴露的信息；两者均可由小型穷举完成，但都不等于已经测到真实 Agent 的记忆作用。

### Cited Findings

- 经典 CTP 与 double-valued graph 所求的是依赖逐步揭示信息的策略，而非一条预先固定的最短路径；其比较对象却可使用完整实例信息。这是在线决策与离线最优的区别。[Papadimitriou 与 Yannakakis，§1、§4](https://sites.cs.ucsb.edu/~suri/cs235/Rlist/noMapNavigation.pdf)
- 部分监测路径论文刻意区分“看见选中边的各自损失”与“只看见路径总损失”，并使用共享边的反馈更新多条路径的估计。反馈粒度是问题定义的一部分。[György 等，§3–4](https://jmlr.org/papers/volume8/gyoergy07a/gyoergy07a.pdf)
- 资源约束算法在部分路径标签上保留累计资源和成本，而不是只给每个物理节点保留一个“最好到达距离”。[Ahmadi 等，正文搜索算法、Algorithm 2](https://ojs.aaai.org/index.php/AAAI/article/download/17450/17257)

### Inferences

以下是本项目可采用的设计工具，不是上述论文已经证明有效的记忆指标。

**1. 保留地理图，给校验器使用辅助状态。**

地理图仍为 \(G=(V,E)\)。用于规则求解的状态可以另写为

\[
x=(v,q,r,t,g),
\]

其中 \(v\) 是地点，\(q\) 是会影响行动后果的携带或局部状态，\(r\) 是剩余资源，\(t\) 是必要的时间／条件，\(g\) 是当前任务进度。只加入实际规则需要的字段，不预设都必需。同一地点在不同 \(q\) 下可能对应不同合法转移或代价，因此在这个展开状态空间中搜索，才能正确核对执行。

这类 product graph 是评测器／求解器的辅助对象。面向轨迹分析的节点仍可保持地点，不必要求 Agent 接收或输出这一状态图。取用、观察等原地动作会改变辅助状态，但在地理图中应保留为节点事件。

对于有限状态、有限预算的微型情境，可以先用穷举或动态规划；已知非负代价时也可在适当展开图上用 Dijkstra／A*。若采用复活、资源补充或时变规则，必须在状态中显式处理，不能照搬静态边权。禁止重复节点的 elementary path 也不能直接限制我们的执行，因为合法准备与恢复本来就可能需要回访。

**2. 把未知事实作为可能世界集合，而不是默认为已学会。**

令 \(\theta\in\Theta\) 表示小情境中可能的局部规则配置。不同 \(\theta\) 可以共享同一公共地理图，却有不同的局部结果。对实际已交付的历史反馈 \(H\)，评测器维护

\[
K(H)=\{\theta\in\Theta:\theta\text{ 与已交付反馈 }H\text{ 相容}\}.
\]

这里 \(K(H)\) 只表示在给定候选规则族下，历史证据足以区分哪些世界；**它不是 Agent 的真实信念，更不是其记忆库内容**。规则族／先验若没有告诉 Agent，校验器还不能假定 Agent 知道这个推断空间。真实保存与检索仍要另外观察和对照。

在微型环境中穷举合法历史，可检查：哪些证据组合确实可由自主行动获得；失败历史会留下什么；只获得部分证据时还剩哪些不确定性。这能避免按“完成过某任务”就假定完整知识。

**3. 用同一公共观察下的不同世界检查信息是否有作用。**

构造两个候选世界 \(\theta_a,\theta_b\)：当前任务、地点、公共地图与直接观察相同，但某项由先前经历揭示的事实不同。检查获得该事实后，合理行动是否会随之变化，或能否省去有成本的重新调查。局部应对、取用与操作顺序均可，不要求差异必须是选另一条路。

若某个固定行动／策略不依赖该事实，就能在所有候选世界同样好地处理这类情境，则这条事实在所构造的范围内没有形成强的信息需求。反过来，两世界适合的局部行动不同，是有用的设计证据；它不是“每项任务必须只有一个正确第一步”的要求，公共安全探查仍可能合理。检查单步相同也不足以断言整个任务不需要历史，要继续看后续策略和调查代价。

可验证要求应同时包括：不同实际历史对应不同的有用选择；历史交付的证据确实能区分相关情境；没有不付额外代价且同样好的公共通用方案；当前也不能免费完整重查该事实。若免费观察就能重新得知答案，或无代价“全部准备”覆盖所有情境，仅仅当前初始观察相同仍不足以说明记忆有用。即使以上检查通过，也不推出无记忆必然失败：重新调查可能成功，记忆的作用可能表现为少调查、少重复或提前准备。

**4. 分别核对“信息有价值”与“有信息后很难规划”。**

先给微型求解器相关事实，确认其能用较短、直接的执行完成目标，并核对不依赖微小成本差或大量路线组合。再限制到历史实际可支持的信息，检查还需要调查什么。这比先找一条全知最短路，再把所有距离差都叫作遗忘，更接近本轮要解决的设计问题。

全知解仅回答：“这些事实成立且都已知时，怎样合法执行？”它不知道真实 Agent 是否接触过相关反馈，也不知道某次探索会给后续带来什么价值。全知差距同时可能包含合理学习、规划差异、偏好和记忆问题，不能自动变成记忆分数。

### Gaps

- 没有冻结行动、反馈及稳定性规则之前，尚不能计算真实可达的 \(K(H)\)，也不能承诺上述穷举的规模。
- 上述方法只提供机制和可行性校验；真实 Agent 是否能自主发现信息、产生记忆并用于后续任务，仍需要独立运行验证。
- 本分支不提出最终“公平收益”公式，也不将某个在线竞争比或遗憾定义直接指定为论文指标。

## 地理轨迹图能保留什么，为什么不能单独证明记忆使用？

### Takeaway

有顺序、有属性的地点通勤多重图，能保留许多成功／失败结果未显示的行动过程。但图是行为的表示；缺少反馈与历史条件时，它不能唯一还原 Agent 知道什么，更不能单独识别行为是否由跨 session 记忆造成。

### Cited Findings

- 在线全图探索的定义把“到达后得到什么信息”与“实际走出的覆盖游程”分别规定。竞争分析比较游程长度，不声称由长度就能识别内部知识。[Fritsch，§1](https://arxiv.org/html/2004.06690v2)
- 部分监测路径模型在相同路径动作之外另设反馈变量；只观察总损失与观察各边损失是不同模型。[György 等，§2–3](https://jmlr.org/papers/volume8/gyoergy07a/gyoergy07a.pdf)

### Inferences

**一个直接反例：**两次执行沿完全相同的地点序列行走，其中一次在某地点取用物品，另一回没有；后续同一路段的进入状态和代价可以不同。只有无标签的节点／边结构会丢掉区别。进一步，即使行动、携带和结果均相同，一次可能依赖历史记忆，另一次可能靠当前说明或偶然选择，因此完整行为也不能唯一标识内部原因。

适合保留的记录是：

- 每次实际通勤分别成边，带顺序、方向、时间和任务／生命标识；正常移动与复活等恢复分别标记。
- 基础距离、实际资源代价及进入前影响结果的状态分开保存。
- 原地动作与交付反馈作为地点关联事件，并与触发它们的边和时刻相连。
- 对相关事实保留实际暴露来源；未暴露、部分暴露与后续重新观察均可区分。

这些记录可以显示“先准备再进入”“遇到后返回调查”“曾获得证据后又重复承担同一后果”等不同过程。它们不预先规定折返、环或边多一定差；首次探索、完成委托需要的返程和必要恢复都会产生相似的结构。

若要把行为变化归因于跨 session 记忆，应从同一实际历史检查点建立保留／清除记忆等适当对照，让当前任务、公共地理与环境保持匹配，再观察行动分布及图中过程怎样变化。对照得到的是该干预下记忆通道对表现的影响，仍不能仅凭单个动作宣布内部检索成功。统计量和维度应在机制与实际行为清楚后确定。

### Gaps

- 这四篇图算法论文没有验证完整 LLM Agent 的自主记忆评测方法，不能用其算法保证替代保留／清除对照，也不能据此声称图方法优于其他 benchmark。
- 仅凭现有图记录，无法证明某个 Agent 内部是否形成了特定抽象规则；如果论文要研究内部表征，需要额外证据与方法，本轮暂不扩大到这一目标。
