# 跨 session 自生经验记忆：序贯决策问题的归类与环境设计含义

## 1. 被测 agent 面对的是哪类问题，哪些名称容易用错？

### Takeaway

最接近的正式结构是：**在同一稳定但初始未知的世界中，连续完成多个目标不同的 episode，并通过跨 episode 的信息积累改善行动。** 未知 MDP/POMDP、Bayes-adaptive 建模、多回合适应和探索—利用理论各描述了其中一部分；这不意味着本项目需要训练 RL agent、实现贝叶斯记忆，或者把 benchmark 直接命名为某一种已有问题。

更重要的是区分两层：**agent 面对未知世界中的序贯决策；benchmark 设计者面对环境构造和受控实验设计。** 给前一层贴上 POMDP 标签，不会自动解决后一层的有效性问题。

### Cited Findings

以下四项均实际读取了论文主文的所列部分，核查日期为 2026-10-25；不以搜索摘要作为方法定义的证据。

- **Ross、Pineau、Chaib-draa、Kreitmann，2011，JMLR。** §2.3 将未知转移模型的后验加入决策状态；§3.1 区分当前状态的部分可观测性；§3.2–3.3 联合处理状态和模型不确定性。其论文方法包括信念追踪及近似规划。见 [正式出版页](https://www.jmlr.org/papers/v12/ross11a.html)、[主文](https://www.jmlr.org/papers/volume12/ross11a/ross11a.pdf)。作者站点也有稿件，但分页与正式版本不同，引用以正式版章节为准。
- **Duan 等，2016，RL²，arXiv v2，2016-11-10。** §2.2 将固定 MDP 内的多次 episode 组成 trial；物理初态在 episode 间重采样，RNN 隐状态跨 episode 保留、跨 trial 清除。算法还在不同 MDP 上进行外层训练。见 [主文 §2.2](https://arxiv.org/pdf/1611.02779)。
- **Guez、Silver、Dayan，2012，BAMCP。** §2 给出历史增广的 BAMDP；§3 用后验模型根采样和蒙特卡洛树搜索近似规划。它优化的是相对于先验和实际信息的期望价值，不是全知真实世界路径。核查的 arXiv PDF 为 2013-12-18 修订版，原研究年份为 2012。见 [论文版本页](https://arxiv.org/abs/1205.3109)、[主文 §2–3](https://arxiv.org/pdf/1205.3109)。
- **Klenske、Hennig，2016，JMLR。** §2–3 讨论未知动力学下的双重控制：行动同时影响物理结果与后续获得的信息。§3.1 展示仅考虑眼前成本可能抑制学习；§4 给出近似方法。其主要设置是连续状态、非 episodic 控制。见 [正式出版页](https://www.jmlr.org/papers/v17/15-162.html)、[主文](https://www.jmlr.org/papers/volume17/15-162/15-162.pdf)。

### Inferences

下表是将上述正式结构映射到本项目后的判断，不是声称文献已经提出了一个与本项目同名或完全等同的 benchmark 问题。

| 类别 | 本项目中匹配的部分 | 不能由这个名称推出的结论 |
|---|---|---|
| 普通已知模型 POMDP | 当前只能看到局部信息，需要根据历史判断未见的当前状态 | 不能因此忽略“世界规律本身未知”。反过来，POMDP 也能通过加入固定隐藏参数表示这一点，和下一行不是互斥模型 |
| 未知 MDP / Bayes-adaptive MDP | 即使当前位置、库存等完全可见，地点属性、操作效果等稳定规律仍可未知；历史能改进对这些规律的认识 | “看得到当前位置”不等于“已经知道世界模型”。贝叶斯后验是一个理想参考表示，不是要求 agent 使用的记忆格式 |
| 未知 POMDP / Bayes-adaptive POMDP | 同时存在局部物理状态不确定性与世界规律不确定性时最完整 | 若 Easy 把决策相关的当前临时状态全都显示出来，就没有必要为了听起来复杂而额外制造状态推断难题 |
| 多 episode 适应 / meta-RL | 世界保持不变、物理任务重置、信息跨 episode 留存的组织方式很接近 | 本项目只做测试时，不必外层训练 agent，也不必更新模型参数；外部文件、数据库、记忆工具都可承担持久信息通道 |
| 双重控制 / 主动探索 | 自由行动既完成当前任务，也决定会获得什么证据；探索有代价与未来收益 | 不需要要求 agent 精确计算信息价值，也不宜把昂贵的多步信息规划当作 Easy 的主要难度；连续控制论文的求解器不能直接照搬 |

因此，研究描述可暂时用：**“在共享未知世界中的跨 session 经验积累与利用”**。正式建模时再交代它是多目标、多 episode 的未知 MDP/POMDP，以及跨 episode 的信息通道被限制为 agent 自生持久记忆。这是我们的组合性描述，不是宣称发现新的基础问题类别。

尤其要区分三种不确定性：

1. **当前状态未知**：例如当前某处的临时状态尚未观察到。
2. **世界规律未知**：例如某操作在某种条件下会产生什么结果。
3. **未来外生事件未知**：例如之后什么时候下雨。

三者不能用“有记忆就应该知道”一并处理。稳定规律有跨 session 价值；未来独立或不规则事件的实现不应被要求记住。若当前条件影响行动，可以将当前条件作为当前观测提供，让历史帮助理解其后果。

### Gaps

- 这四篇论文提供问题结构和求解思想，不足以证明本项目的实验贡献或 novelty；本笔记不作该结论。
- 本项目底层机制尚未重定，所以目前不能最终判定 Easy 是否需要真正的物理部分可观测性，还是仅“可见状态、未知规律”已经足够。
- 原始双重控制工作年代较早；本次以可读的 2016 年原研究和推导作为依据，没有声称通读 Feldbaum 原始俄文论文。

## 2. 怎样给出少量但够用的形式定义？

### Takeaway

先分清 **稳定世界参数、当前短期状态、当前目标、公共地图、自生持久记忆** 五件事。记忆不属于地图几何，也不能用执行图取代当前完整状态。

### Cited Findings

- 采用“物理状态与未知参数分开”的思路，依据 [Ross 等 §2.3、§3.2–3.3](https://www.jmlr.org/papers/volume12/ross11a/ross11a.pdf)；采用“episode 重置但信息跨 episode 延续”的组织参考 [RL² §2.2](https://arxiv.org/pdf/1611.02779)。下面的公共地图、外部记忆边界及多目标安排是针对本项目拟定的模型，不是这些论文的原实验设置。

### Inferences

**建议的最小模型。** 一张世界实例有地理图 \(G=(V,E)\) 和稳定参数 \(\theta\)。同一轮多个委托共享 \(\theta\)，但 agent 最初不知道其取值。\(\theta\) 可以描述地点的局部属性、某操作的后果、某条件与操作后果的关系；不预先限定为“危险—工具”对应表。

第 \(k\) 个委托提供公开目标 \(q_k\)，有短期物理状态 \(x_{k,t}\)、动作 \(a_{k,t}\) 和交互反馈 \(o_{k,t}\)：

\[
x_{k,t+1}\sim T_\theta(\cdot\mid x_{k,t},a_{k,t},q_k),\qquad
o_{k,t+1}\sim O_\theta(\cdot\mid x_{k,t+1},a_{k,t},q_k).
\]

\(x\) 至少包含会影响下一步后果的变量，例如地点、持有物、剩余资源、当前环境条件和本委托进度。\(o\) 包含实际交付给 agent 的当前观测、行动结果及可见代价。确定性游戏是上述概率模型的特殊情况，不必为了符合理论而加入随机性。

任务边界：

\[
x_{k+1,0}\sim\rho(\cdot\mid q_{k+1},\theta),\qquad
\theta_{k+1}=\theta_k.
\]

这表示任务相关物理状态按已定义规则重置，世界中可积累的稳定规律保留。若未来决定让某些物理改变永久保留，就必须明确列为另一类持久世界状态，不能悄悄混入“只有记忆跨 session”假设。

定义 \(B_k\) 为所有实验条件一致可见的公共地理信息，例如已提交节点、道路、基础距离；定义 \(m_k\) 为 agent 自己通过记忆机制保留下来的信息。新 session 中的行为可写为：

\[
a_{k,t}\sim\pi_A(\cdot\mid q_k,B_k,m_k,h_{k,t}),\qquad
m_{k+1}=U_A(m_k,H_k).
\]

其中 \(h_{k,t}\) 是本 session 到当前为止的上下文，\(H_k\) 是实际发生的完整交互；\(U_A\) 是 agent 自主写入、更新和保留记忆的过程。公式是抽象接口：记忆可在任务中多次写入，也可经检索工具按需读取，不要求每次把整个 \(m_k\) 注入提示词。新 session 清除 \(h\)，只按协议保留 \(m\) 和公共 \(B\)。环境不把作者写好的经验点发给 agent。

**这个区分为什么重要：** 能看到当前位置、库存和天气，仍可能不知道某动作在这里的后果。此时短期物理状态可以是可观测的，而转移或代价参数仍然未知，跨 session 记忆依然有用。不能把“世界全部已知”当作“物理状态可见”的同义词。

**贝叶斯表示只是分析参考。** 理想分析者可以维护“当前物理状态和稳定参数在实际证据下还可能是什么”的联合信念。若只关心规律，则维护关于 \(\theta\) 的信念即可。LLM agent 可以用自然语言、案例、程序、图或数据库记忆；不要求显示概率，更不要求梯度训练。保留整段日志、提炼一个规则、记录一个错误案例都属于可比较的自生信息处理方式。

把 \(\theta\) 加入隐藏状态并令其保持不变，就能得到普通增广 POMDP 的表示。因此，“普通 POMDP”与“Bayes-adaptive”是建模重点和表示方式的不同，不能说前者绝对不能容纳未知规则。Bayes-adaptive 模型明确追踪模型知识如何随经验变化，对我们解释“未知—获证—后续行动”更方便。

**图是执行的投影。** 完整轨迹 \(H_k\) 可以投影成位置节点和有序通勤边组成的 \(\Gamma_k\)。但同一个地点在不同库存、资源或条件下，动作后果可以不同；只用地点当状态通常不满足 Markov 性。应区分：

- 地理图：世界的空间结构。
- 完整决策模型：含当前状态和稳定未知参数的动力学。
- 执行图：轨迹在地点及边属性上的可分析表示。

不一定把完整状态扩成巨大图；可以保留位置节点，将操作、条件、库存、代价和先后顺序作为事件与边属性。这是表示选择，是否足够要由将来要区分的行为决定。

### Gaps

- \(\rho\)、可见状态字段、操作集合和稳定参数族都尚未定稿；本模型明确了应填写的边界，没有替用户锁定玩法。
- 自然语言记忆的内容质量和内部检索是否发生，不能从上述接口公式或执行图自动识别；需要额外实验或可观察工具记录。

## 3. 这些问题已有怎样的解法，怎样用于重做 benchmark？

### Takeaway

理论求解路线是“根据实际经历估计未知世界，再将当前收益与获取信息的收益共同用于行动”；本项目应借其拆分方式设计环境，而不是把整个 Bayes-adaptive 求解问题都转嫁给被测 agent。**先构造有行动价值的未知信息，再用简单的已知信息条件验证规划没有喧宾夺主。**

### Cited Findings

- [BAMCP §3](https://arxiv.org/pdf/1205.3109) 是未知 MDP 的一条近似求解路线：从当前后验采样模型并做树搜索；它提供的是相对已有信息的规划思想。
- [Ross 等 §4–5](https://www.jmlr.org/papers/volume12/ross11a/ross11a.pdf) 通过有限近似、信念监控和在线搜索处理未知 POMDP 的计算难度；并非要求所有方法都用一种固定记忆结构。
- [双重控制主文 §3.1、§4](https://www.jmlr.org/papers/volume17/15-162/15-162.pdf) 说明信息获取与当前行动的耦合，以及精确处理这种耦合的困难；本项目可以从中理解自由探索，不必实现论文中的连续控制算法。

### Inferences

**一、重设计先从环境机制规格开始，而不是先排八项任务。** 对每个候选机制填写一行：

| 需要明确的字段 | 具体要回答的问题 |
|---|---|
| 已知操作语义 | agent 一开始就应知道怎样合法操作，以及基本反馈如何读取；不能把接口猜谜当经验积累 |
| 稳定未知量 | 世界里究竟什么尚未知、能跨委托保持、有可能通过交互获知？ |
| 获证方式 | 哪些观察或操作会给出区分不同规律的证据？只有失败还是也有低代价调查、成功试用等方式？ |
| 证据强度 | 一次交互已经足够，还是仅提供部分证据？agent 有没有理由知道证据的适用范围？ |
| 当前可见条件 | 后续行动要结合哪些当前状态？这些状态是否能够在行动前获知？ |
| 信息的后续用途 | 知道该信息会怎样改变另一项目标下的操作、准备或执行顺序？ |
| 重新获取的代价 | 忘记后可否现场再查或再试？代价是否会自然留在轨迹、事件或边属性里？ |
| 公开信息边界 | 公共地图、提示和界面会不会在关键时刻把本来要记住的答案重新给出来？ |

这一步允许推翻“到达即完成测绘、携带即自动生效、危险只扣体力”等现有规则，但不预设必须添加更多按钮。规则是否保留，依据它能否产生上述信息链决定。

**二、用“同当前输入、不同历史需要不同选择”检查信息是否真的有用。** 这是设计条件，不是先确定最终评分维度。

- 为一个机制构造两个合法的世界实例，它们的稳定未知关系不同，当前公开目标、地图几何、可见短期条件和可选动作保持一致。
- 在某个决策点，如果两世界的合理行动始终相同，那么那条未知信息对这个决策没有必要价值，不能仅因作者把它标为“经验点”就算成立。
- 应存在一些决策点：过去真实交互可以区分两世界；当前输入本身不能区分；获证后合理行动会不同，而且做错或重新调查有实际代价。
- 多实例中平衡这些未知关系，检查常识、地点名称、固定动作偏好或任务编号是否能替代历史。对自然语义有明显暗示的事实，不能仅改名就假定预训练泄漏消失。
- 不要求所有后续委托都必须用到每条经验，也不要求形成唯一正确路线。只需事先证明设计存在足够的、有区分力的信息依赖，再根据实际经历判断哪些机会真正发生。

在容易检查的有限机制里，可以枚举世界参数取值和少量局部动作，验证“换参数会换合理行动，获得证据后能明确判断”；不必一开始求解庞大的全局信念空间。

**三、把记忆困难和规划困难分别做设计诊断。**

1. **完整世界信息条件**：让参考求解器知道真实机制，用来查任务可解性、代价范围和意外捷径。这是工程检查，不是 agent 应达到的记忆 GT；它可能使用了 agent 根本没见过的信息。
2. **实际历史信息条件**：只把该次运行先前真正交付过的相关原始证据放入当前上下文，保持当前任务和世界不变，检查“信息就在眼前时”决策是否仍很难。这是环境设计诊断，不能拿它替代正式自生记忆条件，也不能补入未暴露真值。
3. **正式自生记忆条件**：照原协议隔离 session，让 agent 自己决定记录和检索什么。实际暴露的证据要由环境单独记账，但不据此宣称 agent 已经理解、写入或学会。

若第二种条件仍频繁失败，应优先简化条件推导、操作组合和路线计算；否则正式条件下差异很可能主要反映规划或指令执行。相反，“完整世界信息很好”不能单独证明规划已被排除，因为它可能给了此前不可获得的信息。

这里不制定成功率阈值，也不声称一次诊断足以完成因果归因；其目的是淘汰明显推理过重的玩法。最终比较还需多实例和匹配历史的受控实验设计。

**四、允许每项委托兼具学习与利用，不需要固定收集期/测试期。**

在每次行动后记下实际给出了什么证据。未来任务到来时，按世界规则和实际暴露历史判断哪些信息有机会相关，而不是把“任务 1”机械视为全体 agent 都获得经验的来源。前一任务失败也可能获得有用证据；成功也可能没暴露关键规律。探索位置和证据充分性都是路径依赖的，应作为过程数据保留。

**五、底层机制成立后，再检查图有没有保留有效差别。**

对同一个当前目标，分别执行“提前根据证据行动”“现场重新调查”“重复尝试”“先失败后修正”等合法策略。检查它们是否在有序边、节点操作、条件、代价或恢复过程上留下可区分记录。若不同策略投影成同一个图，可以补充有必要的属性或事件；不能为了挽救纯拓扑指标，反过来强迫 agent 多跑几条路。

图可以显示历史相关的行为后果，却不能单靠图相似度证明内部使用了某条记忆。全知最优路径也不是普遍的评测 GT：合理探索、部分证据和未见信息会使多种轨迹都合理。参考规划器首先服务于设计验证，不应提前变成唯一正确答案。

**建议下一项具体产出**：先写一份环境机制表，提出两三个机制候选；对每个做上述“信息区别性、获证可达性、已知证据下决策难度、图表示可分性”检查，再决定保留哪些基本操作。之后才承载到地图并生成委托流。这里的两三个机制是设计候选数，不是要求最终 Easy 一定混入三套系统。

### Gaps

- 这些理论不会自动生成有效 benchmark，也没有直接给出本项目应采用的机制或最终指标；机制选择仍需小规模执行验证。
- “把相关过去证据放回上下文”的诊断会改变检索负担，正是为了检查规划负担；不能把其与正式记忆条件的全部差值直接称为纯记忆效果。
- 本笔记没有估计对 GA、Hermes 等具体 agent 的可解率，也没有运行真实模型；任何“Easy 对当前 agent 足够容易”的判断都尚待验证。
