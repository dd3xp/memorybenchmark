## 资料与经验

本图从 16 类通用资料中固定选择剖面、岸线、植被、岩性、方位、高程，再加入湖盆声呐和水怪目击两类特色资料。选择在地图制作时确定，运行实验不重新抽取。水怪目击为游戏内观测材料，不是对现实生物存在的判断。

A–H 八种站型与八类资料整体一一对应，每型两座且功能完全一致。没有按字母、方位或常规／特色资料划定的候选站型范围。H 型站的水怪研究主题不揭示处理能力；本版也避免将水怪资料直接配给带有水怪名称的站型。评测器保留全部 8!＝40,320 种候选配对，实际运行始终使用本图的一份固定配对。

## 操作与会话

- `move`：走到一个相邻地点，记录一条有序移动边和真实距离。
- `survey`：在当前段目标主动勘探，消耗一次操作并取得本段资料，不增加路程。
- `process`：携带资料在基站主动提交处理；成功或不匹配都会反馈本站能力。不匹配保留资料，可换站重试。
- `submit`：两段处理完成后回 C 营地主动交付一次。
- `read`：免费返回当前公开状态与地图，不提供能力答案或历史反馈。
- `abandon`：结束本项。预算耗尽也记未完成，已经交付的经验仍有效。

不提供独立 `inspect`。到访不揭示能力，到达目标不自动采集；已完成资料不能重复处理。每项预算 88 次操作，原生会话使用单步动作。每项重置位置、资料、对话及工作记忆；只有 Agent 自主保存的原生持久记忆跨 session。保留与清除分别是独立的完整任务流，各地图从原始基础记忆开始。

主提交正确率为成功 `process`／全部实际 `process` 尝试；同时报告完成率和图上的路程。原地勘探、处理与交付进入节点事件，不制造移动边。实际前序反馈定义后续的经验机会，任务失败不补发经验。
