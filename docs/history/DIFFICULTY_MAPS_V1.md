## 取景与资料

地理原型仅作为地形骨架，不复制真实基础设施、坐标、通行条件或基站能力。游戏道路和权重是固定的抽象配置，不能作为现实导航地图。

- 彩丘：取景限定为张掖七彩丹霞**七彩虹霞台周边的一片彩丘与侵蚀沟谷**，选景窗口设为约 1.5 × 1 千米（1.5 平方公里），不覆盖整个景区或整个核心游览区。窗口是本次作者选定的地形参考尺度，**不是官方景点面积、实测边界或游戏图的 GIS 面积**。[张掖市官方介绍](https://www.zhangye.gov.cn/chzy/zyly/ajjq/202303/t20230318_1007476.html)给出的整个景区为 50 平方公里、核心游览区为 4 平方公里；二者都不能当作本图面积。使用剖面、岩性、高程、坡度、坡向、土壤、地层产状、侵蚀地貌资料。
- 长湖：参考[尼斯湖周边](https://www.visitscotland.com/things-to-do/nature-outdoors/lochs/ness)的两岸、支谷与坡地。八种地理资料为剖面、岸线、植被、岩性、方位、高程、水深、沉积物；四种动物主题资料为疑似水怪目击、水下动物回波、异常尾迹、水域动物环境 DNA。它们是游戏内观察材料，不表示现实中已证实存在水怪。
- 野犬：参考 K’gari 的[中央湖区至东岸片区](https://parks.qld.gov.au/parks/kgari-fraser/journeys/central-lakes-scenic-drive)及[野犬主题](https://www.qld.gov.au/environment/plants-animals/animals/living-with/dingoes/about-dingoes)，使用沙丘、森林、湖盆和海岸结构。地理资料为剖面、岸线、植被、高程、土壤、水深、沉积物、地表覆盖；动物资料为野犬足迹、野犬声学、滨鸟观察、爬行动物活动。
- 野猪林：参考迪恩森林的 [Parkend—Blakeney Hill 林区](https://www.forestryengland.uk/forest-planning/parkend-walk-and-blakeney-hill-walk-forest-plan)和[野猪活动迹象](https://www.forestryengland.uk/article/wild-boar-the-forest-dean)。地理资料为剖面、岩性、植被、高程、土壤、水系、坡度、溪床地貌；动物资料为野猪足迹、野猪翻拱痕迹、鹿类活动、林鸟声学。

动物资料增加题材和处理能力关系，不增加识别谜题、追踪动作或攻击事件。仍然在当前目标通过一次主动 `survey` 获得当前指定资料。

## 能力反馈与评测边界

携带当前原始资料，在站点主动 `process` 后，Normal 返回该站型支持的一至两类资料和本次结果。成功与失败均揭示完整列表，失败保留原始资料，经过站点不揭示能力。同型另一座站可复用该经验，其他可处理站型仍须通过经历获知。

Normal 的合法能力组合过多，不枚举成 Easy 的八阶排列。运行端保存一份固定真值，评测端独立维护实际反馈支持的事实。**未观察的站型保持未知，不能因配置中只有一份实际真值就判定 Agent 已知全部答案。** 新的 `station_knowledge` 层负责集合成员关系、同型传播和机会判断；没有实际计算的兼容世界数量、信息熵及精确未知世界策略参考返回空值。已知真值的最短路线仅供人类设计查看与物理下界诊断。

原生 GA／Hermes 的 MCP 接入、原生记忆方式、high 配置方式和单步交互不变。游戏规则支持多类资料，不向 Agent 写入任何参考记忆。新建 Normal 独立实验默认主循环 180 次模型调用、整理 6 次；Easy 保持 100／6。两条件使用相同预算，值写入冻结清单；`--max-turns` 可在新建时显式指定，恢复时保留原预算。游戏预算分别为 Easy 88、Normal 168 次操作。

2026-11-04 原生试跑启动时发现共享执行器仍以 100 为预算校验上限。该上限已修复为 200，Normal 声明的 180／6 不变；补充回归用例覆盖 GA、Hermes 的完整执行器构造链。六个 Normal 独立组均在任何模型调用或任务开始前完成修正，原配置与源快照留档，正在运行的 Easy 快照不变。

本轮 Hermes 试跑覆盖六张地图各自独立的保留／清除记忆组，共十二个实验、三百个任务 session，并发上限六。调度仅控制资源名额，任何组均不依赖另一组的成功、任务编号或记忆。原始清单的每任务六次、每组六十四次整任务重跑上限保留供历史审计；2026-11-04 改为同一模型请求内恢复，暂时性网关故障在原 session 中等待和重试，每任务累计基础设施等待最多一周，不重复已执行动作，不增加模型调用或任务有效运行预算。原生源码与已完成任务不变，宿主覆盖版本在任务结束后切换并单独归档，详见[独立实验恢复协议](../INDEPENDENT_EXPERIMENTS.md)。任务本身失败仍作为结果保留。服务器每两分钟检查进程，另由定时唤起检查实际任务推进与异常证据。

## 几何校准和规则重放

制作阶段以固定种子检查能力配对与公开距离的关系，不读取新图原生 Agent 成绩。以每一段目标点为出发位置，若最近站距离并列，对并列站等权计算匹配比例。新彩丘为 12.5%，新版溪谷为 11.25%，湖群沿用 8.75%；Normal 三图分别为 10.83%、12.5%、10%。这些比例不是 Agent 正确率，也不是统计显著性估计。

所有地图的每座实体站在至少一个固定委托的阶段路线中具有严格距离优势。为消除无用站点，野犬图的 N1 支路在制作阶段迁至另一个既有岔口；没有扩大地图面积。Normal 调整目标位置时，资料顺序、每种资料五次、每个测点五次保持不变。配置在开始新图原生运行前冻结。

规则验收汇总（历史附件见冻结归档）包括六张图、两种反馈策略的三百个真实内核任务，全部完成并验证移动边、距离、勘探、处理及交付。脚本只从各自实际收到的反馈选择站点；清除策略每项不使用前序反馈。这是规则和经验价值的校验，不是 Hermes／GA 的新成绩，也不承诺原生 Agent 能达到脚本收益。

## 旧 Easy 差异核查

基于已封存的 106 个有效原生 session，三张地图的有效任务完成率都是 100%。此前显著不同的是处理提交正确率，而且跨地图对比的任务窗口不相同。数值核查（历史附件见冻结归档）。

| 保留记忆组口径 | 尼斯湖 | 雾杉溪谷 | 石阶湖群 |
| --- | --- | --- | --- |
| T1–T20 全部处理提交 | 40/48＝83.33% | 40/45＝88.89% | 40/53＝75.47% |
| T2–T20 全部处理提交 | 38/40＝95% | 38/42＝90.48% | 38/45＝84.44% |
| 统一 T2–T11 | 20/22＝90.91% | 20/24＝83.33% | 20/27＝74.07% |
| 最近站碰巧匹配（设计诊断） | 22.5% | 2.5% | 8.75% |

存在三项可核实因素：

1. **统计窗口与冷启动位置。** 尼斯湖 T1 获得七种站型的直接反馈，一一对应规则还可推断最后一种；溪谷 T1 只获得两种，T2 才达到七种。排除 T1 的对比把两图的探索成本放在了不同分母中。应报告全程、统一区间与实际机会条件三个口径。
2. **位置与能力偶然关联。** 旧尼斯湖最近站命中比例明显偏高。新配置校准此关系，且要求等价副本都有路线用途。未修改旧数据使其看起来更均衡。
3. **一次未提前读取经验。** 石阶湖群所有七次后续处理错误均发生在 T4。T1 已保存八条正确配对；T4 输入记忆清单中对应文件 SHA 与 T3 输出一致。T3 在任何处理前调用 `read_file`，T4 则在九次处理调用和最终 `submit` 之后才读取它，其中七次不匹配。这是已有正确经验未在当轮行动前读取的具体证据，不能归为未接触经验或保存错误。有序工具调用及文件校验（历史附件见冻结归档）。

因此，旧结果不支持“尼斯湖任务完成率远高于其他两张”的说法。配置校准解决几何偏差；真实的记忆读取与应用错误仍作为被测行为保留。单次运行不能给出上述因素各自的因果贡献，新的正式图需要另开独立原生运行评价。
