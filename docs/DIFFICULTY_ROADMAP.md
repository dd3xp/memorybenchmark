以下保留2026-11-03至11-05的选图与规则讨论。文中的Hard48、Lunatic64及当时的“当前”字样属于历史设计，不能据此恢复旧方案、旧实验或已作废的64k结果。六张Easy／Normal地图说明见[六图设计](DIFFICULTY_MAPS.md)，历史Hard与Lunatic方案分别见[Hard地图](HARD_MAPS.md)与[Lunatic地图](LUNATIC_MAPS.md)。

## 共同机制

研究 Agent 在跨 session 的相似任务中，自主产生、保存和复用经验的行为。地图与道路公开；基站能力由携带当前资料主动处理的反馈获得。每项委托重新开启 session，仅原生持久记忆跨任务；只对实际收到的历史证据登记复用机会。任务失败不补发经验。处理结果、移动顺序、有向多重通勤边、距离与节点操作均保留。

世界能力配对在制作地图时固定，跨 Agent、条件、重复实验保持相同。同型实体站功能一致。无候选站网分组，无运行时随机配对。Agent 只见匿名地名和版本，真实地理来源及能力真值保留在评测侧。不再用天气、工具、体力增加新难度。

## Easy

八种地理资料，八种站型，每型两座等价站，站型与资料一一对应。每图从通用与当地地理资料池选择固定组合。正式地图：雾杉溪谷、石阶湖群、玄锥熔原（卡普林火山保护区原型）。动物相关资料退出正式 Easy；尼斯湖 Easy 旧版及其结果冻结为历史预实验。

## Normal（本轮实施）

十二种资料＝八种地理＋四种动物相关资料；十六种站型，每型两座等价站。处理能力为固定多对多：每种资料至少有两个可处理站型，站型可支持一种或多种资料。能力须通过游戏交互学习，不能从站名或现实动物常识直接获知。关注更多资料、重叠能力与可替代站型的经验复用。地图范围取局部地区，以能容纳有意义的基站选择为准，不强行翻倍真实地理面积。

三图：尼斯湖水怪（湖岸及附近支谷）、澳洲野犬（K’gari 中央湖区至东岸片区）、野猪林（迪恩森林局部）。主题动物增加可选资料，不改变采集—处理—回营交付的基本任务，也不增加追踪解谜或动物攻击。

## Hard：条件化经验

当前 Hard 采用十二种资料＝八种地理＋四种人文，24种站型、每型两站；两类处理要求、24组合各四次，共48项。首版十六种资料和64项配置保留历史归档。人文选择建筑形制、水工设施、聚落格局、历史道路遗迹。

核心经验形式为「资料＋当前委托明确要求 → 可处理站型」。例如，同一碑刻资料在文字编目要求下可去 A/B 型，在年代校核要求下可去 B/C 型。任务要求直接公开，站型的条件能力通过实际处理反馈获得；规则跨任务固定。同型站在同一条件下完全等价。研究条件匹配及跨情境应用，不要求模型靠宗教、考古常识解谜。

地图可以是有人生活与活动的地区、宗教场所和聚落，不限于遗址，更不要求废弃。也可以参考明确历史时期的地区，例如波西米亚王国范围内的城镇、城堡、乡村和河谷；题材不限定为现代行政区或现存遗址。

2026-11-05 用户明确 Hard 可以采用更大的地区尺度，地理覆盖面积可以比 Normal 大一个量级。后续按面积约十倍作为选景方向，不再把 Hard 限在单座古城核心或单个景点。Normal 当前尚无实测取景多边形，十倍不是已经测得的比例；正式选区需记录实际边界与参考时期，不能把景区总面积与局部游戏取景混比。

2026-11-05 经地区比较与用户确认，Hard 的三个地理原型选为：**约1500年的奥尔恰谷、16世纪上半叶且1565年前的亨比都市腹地、约13世纪的大吴哥中部**。三者分别参考丘陵多中心聚落、岩丘河谷与灌溉腹地、平原水利—聚落网络。首版的取景窗、匿名名称、资料与条件能力规则、64项任务和预算已实现；用户要求三张地图逐张设计，现已用独立的丘谷三桥、岩岸城郊、大池城壕路网替换首版模板，版本为 v2.1。三图均完成独立脚本验收，尚未启动原生模型实验。

先前的波西米亚、雅典卫城、历史布拉格、佩特拉以及单独吴哥城不再是当前三图实施选择；梅萨维德保留为路网核验后的替补。[吴哥整体约四百平方公里](https://whc.unesco.org/en/list/668/)，与单独吴哥城的九平方公里是不同范围，均不能直接代替游戏实际裁切面积。真实人文背景是取景来源，游戏的匿名站型能力仍是人为固定的实验规则。

地理面积、可交互图规模与任务预算分别记录。面积约十倍对应相似形状下约三点二倍的线性尺度，不直接推出节点数、有效任务时限或模型调用预算也需十倍。公开道路、跨地区通道、同型站副本及错误选择的通勤成本应体现扩大后的地域结构；不能只扩大画布或改地名。具体节点数、道路权重、条件组合和预算须在原生试跑前校准并冻结。地图扩大与条件化经验共同构成 Hard 的设计方向；Lunatic 仍以大量相似自产经验的选择与长期复用为重点。

## Lunatic：大量相似经验中的选择与长期复用

此前暂定的重点是：在大量由 Agent 自己产生的、相似而有不同适用条件的经验中，经过较长任务间隔和交错任务后，仍能找出并使用当前需要的旧经验。可增加任务流长度、适用条件组合和相似经验数量，观察错误套用、旧经验重新利用与成本变化。不是由研究者向记忆库写入干扰记忆；干扰经验也必须由合法游戏经历产生。

世界规则仍固定，不以随机改能力制造困难。长间隔与重复接触需单独记录，不能将再次获得现场反馈后的正确行为直接记作跨 session 复用。通勤图与节点行为能支持行为分析；不能仅凭图断言内部发生了遗忘、检索或干扰。

本轮三图采用斯堪的纳维亚、蒙古和安第斯，逐张手写独立路网。每图16资料、24站型各两站、2种公开要求、64项双段任务；32个资料／要求组合各4次，重复间隔至少12项。每项预算保持与 Hard 相同，具体版本和验收见 [Lunatic 地图](LUNATIC_MAPS.md)。

## 本轮新图校准

保留旧配置和实验。首先核对旧结果的分母、任务完成率、主动处理正确率和首次选择正确率，避免将网关中断、不同有效任务区间混成游戏成功率。新图检查能力与近邻选择的偶然一致、资料曝光和复用间隔、每个站型及等价副本的路线用途、已知能力与无历史经验策略的成本差、操作预算和参考路线。脚本重放只验证机制与可行性，不冒充原生 Agent 成绩，也不承诺单次模型运行的收益。
