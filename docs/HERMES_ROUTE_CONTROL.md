# Hermes 连续移动对照

此对照已结束。2026-10-31 起不再新建连续移动实验，GA／Hermes 均按[单步动作规则](ATOMIC_GAMEPLAY.md)运行。下文记录历史配置，旧结果和冻结源码继续保留。

历史实验使用 `--agent hermes --game-access native --movement-mode route`，在原生 MCP 发现的 `game_action` 中增加可选的 `path` 参数。例如 `{"action":"move","path":["J","JN","NL","P"]}`。单步 `target` 仍可用；模式写入实验记录，恢复运行时不能更换。当前入口仅在恢复历史实验时接受这一配置。

路径必须由 agent 给出全部相邻地点，最多 32 步。工具依次执行原有 `move`，每一步独立生成请求、反馈和图边，正常计算操作与道路距离。结果包含逐步 `responses` 和末尾状态。遇错误或任务结束立即停止；不补路、不查询记忆、不修改装备或站点决策。

这是测绘工具的交互粒度对照，Hermes 上游代码、原生记忆、技能和会话机制保持不变。新增的提示只解释 `path` 的用法。agent 自行决定是否批量移动；审计分别统计路径调用、请求的移动步数、实际移动事件及模型调用，不能把“开放了能力”当成“实际使用了能力”。

实跑从原始基础记忆开始，沿用原生 Hermes `e5ea5fd`、Luna、同一地图与隐藏世界、工作种子、64K 上下文，以及每 session 100 次执行调用、6 次整理调用、3,600 秒和 88 次游戏操作预算。按当前协议运行 20 项保留记忆任务和 20 项清除记忆任务。T1 两组独立执行，清除组不更新主线经验；T2–T20 的清除探针仍使用保留主线实际历史检查点。

与此前逐步 Hermes 比较时，跨 session 记忆收益只配对 T2–T20；额外 T1 清除实验单列，不混入 19 项对比。保留失败任务及未到达的触发点。报告路程、操作、成功率、模型调用，以及保存、实际交付和读取时机；单世界的一次自主历史对比不等于总体因果效应。

软件验证使用固定响应驱动原生 Hermes/MCP，完整完成两段委托：5 次连续移动请求产生 26 次真实移动，加处理与提交共 29 次操作、路程 30。每步反馈进入后续模型输入，空上下文与原生 MCP 接入已核查；软件验证不计为模型成绩。
