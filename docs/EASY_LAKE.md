# 雾汀湖 Easy：公开地理图与工具经验

当前场景为 `lake-easy`，版本 `lake-easy-2.0`，更新于 2026-10-19。游戏名称、地点、营地、任务提示、环境标识和背景图使用虚构命名，不向 Agent 提供地形参考来源或真实地名。地理骨架的研究出处保留在旧版研究文档中，不作为任务输入。

## 研究边界

本场景重点考察 Agent 自主积累的风险与工具经验如何影响后续准备和行动。地理路线作为公开任务成果跨 session 保留，让两组都能查到已经点亮的地点、连接和基础距离。比较关注提前取用正确工具、重复无防护进入、无关准备与事后折返，而不要求 Agent 将整张地理图重新写进记忆库。

共享图不记录危险类型、危险代价、工具库存及存放位置、工具效果、携带历史或现场反馈。这些事实必须通过 Agent 自己的实际经历获得，再由其原生记忆机制保存。当前地点的工具库存仍会正常公开；已经在本任务重新看到的信息不能算作只能由跨 session 记忆提供。

## 地图与营地

保留 31 个地点、31 条无向基础通路，连通且只有一个独立环。三个营地使用虚构名称：苇湾 `C0`、岚丘 `C1`、石湾 `C2`。每项委托指定起点和提交营地，不依赖上次提交位置；经过营地不会补体力或自动交付。

每次到达自动记录本任务的地理成果。成功在指定营地提交后，实际走过的节点与边进入累计地图；仅看见但未到达的邻居不点亮，失败不提交新成果。`observation.map.nodes/edges/distances` 合并本任务已发现信息与此前提交的地理图，`charted` 表示此前点亮，`surveyed` 仍只表示本次到达。

因此，旧地点虽然能在图上看到，新委托仍须实际到达并回营提交。Agent 的初始提示、`read` 和其他游戏工具结果都包含共享地理图的文字及结构化版本；人类和观测台显示同一公共地理成果。

## Easy 的两组经验与四项委托

Easy 只设置两个风险地点：灰脊坡口 `P1` 的湿滑岩坡、苔溪浅滩 `R1` 的湿冷沟溪。每任务体力 70，无对应工具每次额外消耗 38，正确工具降至 2；第二次无防护遭遇一定失败。天气仍随预设时间表变化，但不改变本图风险。

工具都不在测绘目标或必经主路上：防滑工具位于 `E1 → U1 → D1` 的尽头，涉溪工具位于 `N2 → B3 → B4` 的尽头。只到达取用地点才公开库存；取用后自动生效，下一任务携带状态清空。

| 委托 | 起点 | 本次目标 | 提交营地 | 参考风险次数 | 正确准备的体力需求 | 不取工具的最小体力需求 |
| --- | --- | --- | --- | ---: | ---: | ---: |
| T1 坡口初测 | C0 | P1 | C1 | 1 | 14 | 44 |
| T2 林缘往返 | C0 | N1 | C0 | 2 | 24 | 90 |
| T3 浅滩初测 | C2 | R1 | C2 | 1 | 20 | 44 |
| T4 林道往返 | C2 | S1 | C2 | 2 | 24 | 84 |

T1、T3 允许首次无防护试错后完成；T2、T4 需要准备对应工具，错误工具不能替代。每项参考路线最多经过两次风险，不安排长距离多风险综合关。自由探索始终开放，Agent 自己的额外绕行和重复进入仍计入实际轨迹。

表中路线由全知静态求解器生成，并在规则引擎中重放，用于校准任务可行性；不代表 Agent 已学会对应经验，也不是记忆效果实验。

## 保留／清除干预

两组从同一实际历史检查点复制相同世界，包括已提交的地理图；干预只改变 Agent 的原生记忆目录。清除记忆不会清除公共地图，也不会补充危险或工具知识。只有保留组推进公共历史，清除探测的新轨迹不进入后续公共地图。观测回放不会提前加入未来提交或同一任务另一分支的成果。

每任务仍启动独立新 session，历史对话、工作记忆与临时文件不保留。公开地理图是显式环境状态；Agent 自主产生的经验仍仅通过记忆库传递。新实验记录 `geography_protocol=shared_submitted_geography` 并冻结初始世界快照。旧实验按其原始配置重放，不与新版结果混算。
