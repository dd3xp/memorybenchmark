# 原生 Agent 的精简游戏反馈

新原生实验默认使用 `station-native-memory-3` 提示协议和 `station-compact-feedback-1` 回显协议。公开地图在委托开始时完整提供；普通动作只返回当前任务、两段要求及当前进度、位置、邻居与道路距离、资料状态、操作预算、可用动作、本次反馈与结束状态。站点能力仍由现场 `inspect` 或 `process` 正常交付。

需要全图时，Agent 可调用 `game_action({"action":"read"})`。它返回完整公开地图和规则，不消耗游戏操作、不生成移动边，也不回放历史站点能力。一次工具调用仍可能占用模型调用和时间预算。任务提醒继续在每次模型请求中提供两段完整要求，避免原生上下文压缩后丢失任务。

人类网页沿用完整响应。原始权威事件继续保存完整状态；精简发生在游戏适配器返回给原生 Agent 的响应中。每个新 session 另存 `game-deliveries.jsonl`，记录开局、查询、动作、请求重试和宿主终止的适配器响应；摘要记录该文件哈希。它便于核对输出内容，是否进入模型输入仍须结合原生请求日志确认。

## 历史动作重放

用已公开的 Hermes 联程轨迹，对每个任务的同一个主线检查点分别重放保留／清除分支；完整与精简两种呈现执行完全相同的历史动作。[逐项校验与响应样例](assets/station-compact-feedback/replay-validation.json)覆盖全部 39 个 session、1,747 次操作、1,542 条通勤边，35 个成功及 4 个实际放弃均保留。两种模式的原始事件、完整当前状态、现场反馈和已发表的执行图逐项相等。

|普通动作响应 JSON|完整|精简|

|每次平均字符数|9,218|1,017|
|全部字符数|16,103,871|1,776,586|
|全部 UTF-8 字节数|19,355,656|2,129,874|

字符减少 89.0%。统计使用 `json.dumps(..., ensure_ascii=False)` 默认分隔符，包含结构化响应与文字反馈，不包含开局地图、主动 `read`、Agent 原生包装或模型 token。重放没有调用真实模型，不能据此推断记忆收益或整轮 token 节省。

## 实验版本与对照

原生试跑入口的 `--feedback-mode compact` 为新运行默认值；指定 `--feedback-mode full` 可在同版代码和提示下运行完整回显对照。模式和协议写入 `pilot.json` 及各 session 摘要，续跑不能更换。旧目录没有此字段时按 `full` 解释，原有源码指纹检查继续拒绝代码变动后的混合续跑；历史结果不改写。

两种模式共享同一游戏内核、MCP 工具、GA／Hermes 原生循环和记忆工具。后续真实对照应使用新目录、相同世界与预算，并分别从各 Agent 的原生基础库开始。

真实原生接入可使用脚本模型离线检查，支持 `scripts/check_station_native_sessions.py --feedback-mode compact` 或 `full`。该检查核对完整 `read` 和精简动作确实进入原生模型请求、交付日志哈希、两段同 session、记忆保留／清除、空历史和预算后同会话整理；人工标记仅用于软件测试。
