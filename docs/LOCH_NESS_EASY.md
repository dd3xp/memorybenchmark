# 尼斯湖 Easy：地图与任务流

本图为 Cartographer’s Notebook（测绘手记）的第一张 Easy 地图，场景标识 `loch-ness`，版本 `loch-ness-easy-1.0`。它采用真实地理格局和经明确改编的游戏路线；原型 `valley` 与渡口校准 `river` 继续保留，用于旧记录重放。

## 地理依据与改编范围

尼斯湖位于苏格兰高地的大峡谷中，是狭长湖体。NatureScot 将尼斯湖列为苏格兰大型淡水湖，并说明大型湖盆常由冰川塑造；大峡谷断层构成该区域的地形骨架。[NatureScot：淡水湖](https://www.nature.scot/landscapes-and-habitats/habitat-types/lochs-rivers-and-wetlands/freshwater-lochs)、[NatureScot：地质基础](https://www.nature.scot/landforms-and-geology/scotlands-rocks-landforms-and-soils/rocks-and-minerals/scotlands-geological-foundations)

西岸的大峡谷步道经过 Fort Augustus、Invermoriston、Drumnadrochit；南岸存在 Foyers 峡谷与 Farigaig 森林等地形，为两岸主通路、支沟和林间支线提供依据。[VisitScotland：大峡谷步道](https://www.visitscotland.com/info/tours/great-glen-way-loch-ness-57e84651)、[VisitScotland：尼斯湖地景](https://www.visitscotland.com/places-to-go/loch-ness/things-to-do)

游戏保留湖体西南—东北走向、两岸分隔、沿岸通路和相关地名。节点坐标是排版坐标，边权是游戏体力／时间单位。三处营地、护林屋存放的工具、具体支沟走法及风险位置均为实验设计，未声称对应现实设施或可实际通行的徒步路线。背景图为自行绘制的地理示意，不是实测地图。没有把雪崩、老虎或湖怪作为尼斯湖的现实危险。

## 为什么归为 Easy

难度由规则和决策结构控制：31 个地点、31 条无向基础通路，连通且只有一个独立环；平均度为 2。两岸主路之间没有大量捷径，工具点位于支线尽头，沿岸另有不提供工具的探索支线。距离不完全相等。因而地图点亮之后，仍需要规划绕行取用、顺序与回营，而不能在密集连边中直接横穿。

Easy 只有两类固定风险、两类自动生效的工具；工具不消耗、不叠加携重规则。天气仍按预设不规则时间表变化，但本图风险不随天气／昼夜变化。自由探索从第一项任务起开放，任务流逐步增加需要处理的风险次数，不锁定探索阶段。

## 体力、工具与营地

- 每项任务体力 70，移动按边权扣除体力；到达自动测绘。
- 每次进入风险地点独立结算。无对应工具额外消耗 38；对应工具将额外消耗降至 2。两次无防护遭遇的风险代价已达 76，因此第二次必定耗尽体力。
- 防滑攀行工具位于 `E1 → U1 → D1` 支线；涉溪防护工具位于 `C1 → U2 → D2` 支线。两个工具点都是度为 1 的末端，不是目标或主路节点。取完需要原路返回；任务提示和未访问地图不公开库存位置。
- 三个营地为多里斯 `C0`、德拉姆 `C1`、奥古斯都 `C2`。所有委托固定从 `C0` 出发；这使任务起点不被上次的成功、失败或提交选择改变。新 session 的物理复位包含返回出发营地、恢复体力与清空携带工具，复位不记作 Agent 的通勤。
- 每项委托指定提交营地。到达测绘目标不能提交，抵达错误营地也不能提交。途中经过营地不会自动提交、补体力或重置工具。
- 失败之后仍能启动后续任务，已交付反馈仍供 Agent 自主整理；系统不补发它没有经历过的经验。

以下为全知静态求解器给出并在真实规则引擎重放的可行路线。风险次数包含回程重复进入。它用于检验规则与任务难度，不代表 Agent 应已掌握的记忆 GT，也不是模型实验结果。

## 地图点亮与记忆边界

本次到达记录在 `observation.map`，下一任务清空。成功在营地提交后，实际到达的节点与实际走过的边进入累计地理成果；仅看见但没有到达的相邻地点不点亮。失败、放弃或会话预算耗尽不提交成果。累计成果不保存危险、工具库存、应对条件或现场反馈。

累计地图只用于人类游玩和观测台显示，默认点亮，可切换查看。正式 Agent 经 `GameAdapter` 获取的观察、文字和工具结果均不包含累计地图；`/api/atlas` 是人类界面的独立读接口，不开放给原生 Agent 沙箱。跨 session 的经验传递仍由 Agent 的原生记忆库完成。

观测台查看清除组时，累计地理成果只来自此前公共历史的成功任务，不能加入同一任务的保留组／清除组另一分支；回放到提交之前不会提前显示该会话的提交成果。累计地图不能代替新委托的到达要求。
